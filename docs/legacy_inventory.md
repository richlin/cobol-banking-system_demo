# Legacy COBOL Inventory

## Source of Truth

`BANKACCT.cob` is the authoritative legacy source for this migration. The Python simulator generated by `setup.sh` is not authoritative.

## Divisions

- `IDENTIFICATION DIVISION`: declares `PROGRAM-ID. BANKACCT`, author, and written date.
- `ENVIRONMENT DIVISION`: declares line-sequential `CUSTOMER-FILE` and `TRANSACTION-FILE`.
- `DATA DIVISION`: declares file records and `WORKING-STORAGE` values.
- `PROCEDURE DIVISION`: implements menu flow, account operations, transactions, interest, and date/time formatting.

## File Records

### CUSTOMER-RECORD

- `ACCT-ID`: `PIC X(10)`, positions 1-10.
- `NAME`: `PIC X(30)`, positions 11-40.
- `BALANCE`: `PIC 9(7)V99`, positions 41-49 in the line-sequential record.
- `ACCT-TYPE`: `PIC X(1)`, position 50.

### TRANSACTION-RECORD

- `TRANS-ACCT-ID`: `PIC X(10)`, positions 1-10.
- `TRANS-TYPE`: `PIC X(1)`, position 11.
- `TRANS-AMOUNT`: `PIC 9(7)V99`, positions 12-20.
- `TRANS-DATE`: `PIC X(10)`, positions 21-30.
- `TRANS-TIME`: `PIC X(8)`, positions 31-38.

## WORKING-STORAGE

- Menu and control fields: `CHOICE`, `WS-DONE`, `FILE-STATUS`.
- Account input fields: `WS-ACCT-ID`, `WS-NAME`, `WS-BALANCE`, `WS-TYPE`.
- Search and amount fields: `WS-SEARCH-ID`, `WS-AMOUNT`, `WS-FOUND`, `WS-NEW-BALANCE`.
- Date/time fields: `WS-CURRENT-DATE`, `WS-YEAR`, `WS-MONTH`, `WS-DAY`, `WS-CURRENT-TIME`, `WS-HOUR`, `WS-MINUTE`, `WS-SECOND`, `WS-DATE-STRING`, `WS-TIME-STRING`.
- Statement counter: `WS-STMT-COUNT`.

## Procedure Paragraphs

- `MAIN-PARA`: menu loop with options 1-7.
- `CREATE-ACCOUNT`: accepts account fields and writes a customer record.
- `VIEW-ACCOUNTS`: reads and displays all customer records.
- `DEPOSIT-MONEY`: accepts account and amount, then performs `UPDATE-BALANCE-ADD`.
- `WITHDRAW-MONEY`: accepts account and amount, then performs `UPDATE-BALANCE-SUBTRACT`.
- `UPDATE-BALANCE-ADD`: sequentially finds the first matching account, adds the amount, rewrites the record, and logs `D`.
- `UPDATE-BALANCE-SUBTRACT`: sequentially finds the first matching account, checks funds, subtracts the amount, rewrites the record, and logs `W`.
- `WRITE-CUSTOMER-RECORD`: appends a customer record.
- `MINI-STATEMENT`: reads `TRANSACTIONS.DAT` from the beginning and displays the first five matching records, despite the label "Last 5".
- `APPLY-INTEREST`: applies 2% interest to accounts whose `ACCT-TYPE` is `S` and logs `I`.
- `LOG-TRANSACTION-DEPOSIT`: appends transaction type `D`.
- `LOG-TRANSACTION-WITHDRAW`: appends transaction type `W`.
- `LOG-TRANSACTION-INTEREST`: appends transaction type `I`.
- `GET-CURRENT-DATETIME`: creates `YYYY/MM/DD` and `HH:MM:SS` strings from COBOL date/time values.

## Known Mismatches

- The simulator includes delete behavior, inactive-account status handling, and menu option 8. `BANKACCT.cob` does not implement delete and exits on option 7.
- Current `CUSTOMERS.DAT` rows are 51 characters, with a simulator-era status suffix after the COBOL-defined 50-character record. The migration preserves the status suffix as metadata but does not make it authoritative for behavior.
- README transaction labels mention delete/status behavior that is not implemented in `BANKACCT.cob`.
