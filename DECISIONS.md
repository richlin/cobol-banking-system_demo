# Decisions

## 2026-05-09: Source of Truth for Migration

`legacy/BANKACCT.cob` is the authoritative legacy source for behavior migration. The Python simulator generated by `legacy/setup.sh` is useful only as an execution aid or mismatch reference and must not define the target behavior.

## 2026-05-09: Target Stack

Use Python 3 and SQLite for the modernized implementation because the application is small, file-oriented, and benefits from a low-dependency migration path. Keep the domain logic independent from storage and interface code. Provide an optional FastAPI adapter, but keep verification and core runtime independent of non-stdlib web dependencies.

## 2026-05-09: Simulator-Era Data Suffixes

Current `legacy/CUSTOMERS.DAT` rows are 51 characters and include a status suffix that is not defined by `legacy/BANKACCT.cob`. The migration will preserve this suffix as imported metadata where present, but active banking behavior will follow the COBOL source, which does not implement delete or inactive-account checks.

## 2026-05-09: Verification Commands

Use these commands as the completion gate for the modernized implementation:

```bash
python3 -m pytest
python3 -m coverage run -m pytest
python3 -m coverage report --include='modernized/banking/domain.py,modernized/banking/cobol_records.py,modernized/banking/migration.py,modernized/banking/simulator_compat.py' --fail-under=90
PYTHONPATH=modernized python3 -m banking.cli smoke --db /private/tmp/cobol_banking_smoke.sqlite3
PYTHONPATH=modernized python3 -m banking.migration legacy/CUSTOMERS.DAT legacy/TRANSACTIONS.DAT /private/tmp/cobol_banking_migrated.sqlite3
PYTHONPYCACHEPREFIX=/private/tmp/cobol_banking_pycache python3 -m compileall modernized/banking
```

## 2026-05-09: Simulator-Derived Compatibility Cases

Generate simulator-derived regression cases with:

```bash
PYTHONPATH=modernized python3 modernized/scripts/generate_simulator_test_cases.py
```

The generated `modernized/tests/fixtures/simulator_test_cases.json` contains 64 cases from the `legacy/BANKACCT` simulator. The compatibility test compares logical COBOL fields against the modernized code while excluding simulator-only status suffixes and dynamic timestamps from the source-of-truth contract. The fixture must include both happy paths and edge cases: missing accounts, invalid amounts, empty data files, no-savings interest, old-format records without status suffixes, and multi-step flows.

## 2026-05-10: Repository Layout

Keep banking legacy artifacts under `legacy/` and the modernized Python implementation under `modernized/`. The root remains reserved for project governance, documentation, and shared tool configuration. Do not move or modify the vendored `gnucobol-3.2/` source tree as part of banking-application organization because it is protected vendor material and is not part of the application source split.
