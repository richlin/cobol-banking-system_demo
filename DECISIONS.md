# Decisions

## 2026-05-09: Source of Truth for Migration

`BANKACCT.cob` is the authoritative legacy source for behavior migration. The Python simulator generated by `setup.sh` is useful only as an execution aid or mismatch reference and must not define the target behavior.

## 2026-05-09: Target Stack

Use Python 3 and SQLite for the modernized implementation because the application is small, file-oriented, and benefits from a low-dependency migration path. Keep the domain logic independent from storage and interface code. Provide an optional FastAPI adapter, but keep verification and core runtime independent of non-stdlib web dependencies.

## 2026-05-09: Simulator-Era Data Suffixes

Current `CUSTOMERS.DAT` rows are 51 characters and include a status suffix that is not defined by `BANKACCT.cob`. The migration will preserve this suffix as imported metadata where present, but active banking behavior will follow the COBOL source, which does not implement delete or inactive-account checks.

## 2026-05-09: Verification Commands

Use these commands as the completion gate for the modernized implementation:

```bash
python3 -m pytest
python3 -m coverage run -m pytest
python3 -m coverage report --include='banking/domain.py,banking/cobol_records.py,banking/migration.py' --fail-under=90
python3 -m banking.cli smoke --db /private/tmp/cobol_banking_smoke.sqlite3
python3 -m banking.migration CUSTOMERS.DAT TRANSACTIONS.DAT /private/tmp/cobol_banking_migrated.sqlite3
PYTHONPYCACHEPREFIX=/private/tmp/cobol_banking_pycache python3 -m compileall banking
```

## 2026-05-09: Simulator-Derived Compatibility Cases

Generate simulator-derived regression cases with:

```bash
python3 scripts/generate_simulator_test_cases.py
```

The generated `tests/fixtures/simulator_test_cases.json` contains 64 cases from the `BANKACCT` simulator. The compatibility test compares logical COBOL fields against the modernized code while excluding simulator-only status suffixes and dynamic timestamps from the source-of-truth contract. The fixture must include both happy paths and edge cases: missing accounts, invalid amounts, empty data files, no-savings interest, old-format records without status suffixes, and multi-step flows.
